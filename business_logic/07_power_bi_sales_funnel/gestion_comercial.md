# Gestión comercial

Esta pestaña muestra la gestión por asesor, proyecto y periodo. Permite analizar el avance de cada asesor en las etapas del embudo.

| Indicador | Definición |
|---|---|
| Captaciones total | Todas las captaciones atribuidas al asesor, incluidos nuevos leads y recontactos. La normalización evita que la misma persona se fragmente por nombres, usuarios o variantes. |
| Leads únicos | Captaciones consideradas nuevos leads; excluye recontactos de clientes con relación comercial previa. |
| Contactos total | Gestiones comerciales realizadas. No son clientes únicos: un cliente puede tener varias llamadas, mensajes o contactos. |
| Contactos efectivos | Subconjunto de contactos cuyo resultado cumple la clasificación comercial efectiva. La diferencia frente a contactos totales representa intentos sin éxito o gestiones no efectivas. |
| Citas generadas | Citas creadas en el periodo, atribuidas al asesor y proyecto relacionados. Generarla no implica asistencia. |
| Citas concretadas | Citas que se concretan mediante una visita o gestión posterior válida del mismo cliente y proyecto, ocurrida después de la cita. |
| Visitas, separaciones y ventas | Usan las mismas reglas del [Embudo de marketing](./embudo-marketing), vistas desde la productividad de asesor, proyecto y periodo. |

Una cita puede aparecer como generada y no como concretada si el cliente no asistió, la visita no se registró o no cumple la relación temporal requerida.

La pestaña permite responder cuántas captaciones y leads únicos generó cada asesor, cuántos contactos realizó o hizo efectivos, cuántas citas generó y concretó, y cuántas visitas, separaciones y ventas obtuvo.
